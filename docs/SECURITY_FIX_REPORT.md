## NOT_FIXED / intentionally skipped

1. **C-2 residual — per-client IP identity cannot be guaranteed while stock Next.js route handlers expose no TCP peer.** With no `TRUSTED_PROXIES` configured, `clientIp()` returns `"local"` for everyone (strictest reading of the brief: "if the immediate peer cannot be determined, fall back to `local`"), so direct-to-`:3000` traffic and all proxied traffic share one bucket — rotation defeats nothing, but per-client IP throttling is inert and `metadata.ip` is `"local"`. Operators fronting with Caddy (which *overwrites* `X-Forwarded-For` with `{remote_host}`) must set `TRUSTED_PROXIES=127.0.0.1` (or the proxy CIDR) to re-enable the rightmost-untrusted walk. If the app port is reachable without the proxy (the C-2 scenario), no header logic can fix that — the fix is network binding (`127.0.0.1:3000` + proxy-only ingress), which is an operator/deployment action.
2. **C-1 — `.env` still git-tracked with live credentials; `.next/standalone/.env` still ships secrets in the build artifact.** Rotation + `git rm --cached .env` + history rewrite are operator actions explicitly out of scope; rotation must happen regardless of any code change. (`.env.example` already exists, untracked.)
3. **H-3 remainder — Postgres/Redis-backed counters and plan entitlements.** The item-11 limiter and item-6 webhook throttle are **single-process** and do not coordinate across instances; market/order-intent `TransactionRecord` quotas and `researchRunsPerMonth` enforcement are not implemented (needs the entitlements data-model work, audit M-3). Caddyfile `rate_limit` backstop not added (deploy artifact; not in the fix list).
4. **H-4 — DNS-rebinding race in the SSRF guard.** Requires connect-by-IP pinning (undici `connect.lookup`) or an egress proxy; needs design beyond a 30-line fix and a rebinding regression harness. Untouched.
5. **H-6 — redaction-aware `logError()` helper** and routing the five `console.error` sites through it. Not in the fix list.
6. **H-8 — signed-transaction↔intent content binding** (decode + signer/mint/amount/slippage assertions). Not in the fix list; required before `TRADING_ENABLED` is ever set.
7. **H-3/C-2 defense-in-depth gaps previously noted:** `/api/v1/markets`, `trading/order-intents`, `research/runs` have no per-route quotas (only the global item-11 limiter).
8. **Nonce-based `script-src` / dropping `'unsafe-inline'`** (rest of C-3 and L-3). Not in the fix list.
9. **M-2, M-3, M-4, M-5, M-6, M-7, M-8, M-9, M-10, M-12, H-7-adjacent chunked-body cap, P2 items, docs/claim drift.** All out of scope for this assignment.
